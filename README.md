# 旅行手帳（大阪之旅）

可以隨時編輯的行程網站，部署在 Cloudflare Pages，資料存在 Cloudflare D1。

## 功能
- 在手機上直接編輯行程：標題、時間、詳情；地圖和連結分開填寫「名稱」與「網址」（地圖只填名稱會自動搜尋）
- 每個行程都可以上傳圖片，上傳前自動壓縮；可切換「縮圖／大圖」顯示，個別行程也可以固定用大圖或縮圖
- **分叉路線**：在行程中間分叉成幾條路線（例如「先喫茶後參拜」／「先參拜再喫茶」），只切換不同的部分，分叉前後的行程共用；切換時匯合後的時間自動調整
- **備選方案**：單一行程可以存多個選擇（A／B／C），一按就切換
- **主行程**：新增後，之後的行程時間會自動延後
- **資訊**：不佔時間的資料卡（例如入境須知），編輯按鈕在右上角，不用打卡，內容完整顯示
- **完成打卡**：按圓圈完成後自動摺疊，可以再展開
- **移到備選／加回行程**：任何行程可移到「備選地點」，之後再放回任何一天的任何位置（預設原本位置）；備選地點按類型分頁（餐飲、地點・活動…）
- **子行程**：放在主行程下面，新增時不會改動任何時間；編輯中可用「層級」把主行程改成子行程，或改回主行程
- **是日路線**：每天可切換到地圖，把有地點的行程按次序標示並連成路線；可一鍵在 Google 地圖開啟整條路線或每段交通
- **固定時間 🔒**：航班、訂位等行程不會被推後；時間撞到會顯示提示
- 復原、版本紀錄（保留最近 80 個版本，可以還原）、匯出／匯入 JSON
- 離線查看：在日本沒有網絡時仍可看到最後載入的行程；恢復連線後自動上傳修改
- 可以「加入主畫面」，像 App 一樣使用

## 部署（Cloudflare Workers）

- 網址：https://osaka-trip.yuenszemam.workers.dev
- 設定檔：`wrangler.jsonc`（Worker 名稱、D1 資料庫 ID、靜態檔案目錄 `public/`）
- 入口：`src/worker.js`，負責處理 `/api/*`；其他路徑由 `public/` 提供
- 推送到 GitHub 的 `main` 後，Cloudflare 會自動執行 `npx wrangler deploy`
- 資料表會在第一次開啟網站時自動建立，同時載入預設行程

## 注意
- 網站是**公開**的：任何人有網址都可以查看和編輯。改錯了可以在「⋯ → 版本紀錄」還原。
- 圖片也存在 D1，每張壓縮到大約 1MB 以內。D1 免費額度有 5GB，足夠放幾千張相片。

## 本機開發
```
npm run dev     # http://localhost:8788，用 node:sqlite 模擬 D1
npm run seed    # 從 scripts/original.json 重新產生 lib/seed.js
```
