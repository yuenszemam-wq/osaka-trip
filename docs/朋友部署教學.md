# 朋友部署教學：建立你自己的旅行手帳

跟著以下步驟，你會得到一個**屬於你自己**的旅行手帳網站：

- 有你自己的網址，例如 `https://my-trip.你的名字.workers.dev`
- 行程、相片、支出全部存在**你自己的** Cloudflare 帳戶，原作者看不到
- 全部使用 Cloudflare 免費額度，不用付錢
- 原作者推出新功能後，按一個按鈕就可以更新

整個過程大約 10–15 分鐘，不用寫程式。建議用電腦操作；用手機也可以，只是畫面比較擠。

---

## 第一步：準備兩個帳戶

### 1. GitHub 帳戶（存放網站程式）

1. 打開 <https://github.com/signup>
2. 輸入電郵、設定密碼和用戶名稱，完成驗證
3. 已經有帳戶的話可以跳過

### 2. Cloudflare 帳戶（運行網站和存放資料）

1. 打開 <https://dash.cloudflare.com/sign-up>
2. 輸入電郵和密碼，到電郵收件箱按確認連結
3. 不需要輸入信用卡，也不需要買網域

---

## 第二步：一鍵部署

1. 打開原作者的專案頁：<https://github.com/yuenszemam-wq/osaka-trip>
2. 按頁面上的 **「Deploy to Cloudflare」** 按鈕
3. 如果要求登入，用第一步建立的 **Cloudflare** 帳戶登入
4. 畫面會要求連接 Git 帳戶：選 **GitHub**，按 **Authorize / 授權**，讓 Cloudflare 可以在你的 GitHub 建立一個新專案
5. 會出現一個設定頁，可以修改以下名稱（全部用英文小寫和 `-`）：
   - **Git repository name**（GitHub 專案名稱）：例如 `my-trip`
   - **Worker name**（網站名稱，會成為網址的一部分）：例如 `my-trip`
   - **D1 database**（資料庫名稱）：保留預設或改成 `my-trip`
   - 如果有 **Workers AI** 一項，保留預設即可（用來掃描收據）
6. 按 **「Create and deploy」**（建立並部署）
7. 等 1–3 分鐘，看到 **Success / 部署成功** 就完成了
8. 頁面會顯示你的網址（`https://xxx.xxx.workers.dev`），按它打開

> 找不到網址？到 Cloudflare 主頁 → 左邊選單 **Workers & Pages** → 按你的網站名稱 → 右上角 **Visit**。

---

## 第三步：設定你的網站

### 1. 設定裝置密碼（很重要）

第一次打開網站時，到 **菜單 → 裝置認證**，設定一個密碼（最少 6 個字）。

- 設定後，只有輸入過密碼的手機或電腦才可以打開你的網站
- 每部裝置只需要輸入一次，之後不會再問
- **未設定密碼前，任何知道網址的人都可以看到你的行程**，所以請第一時間設定

### 2. 改成你的旅程

網站會有一個示範旅程「我的第一個旅程」：

- **菜單 → 旅程設定**：改名稱、日期、當地貨幣
- 按 **整理** 可以修改或刪除示範行程，按 **新增** 加入你的行程
- **菜單 → 新增旅程**：可以建立多個旅程

### 3. 加到手機主畫面（像 App 一樣使用）

- **iPhone（Safari）**：按底部的「分享」按鈕 → **加入主畫面**
- **Android（Chrome）**：按右上角「⋮」→ **加到主畫面** 或 **安裝應用程式**

### 4.（可選）同行者和分帳

到 **支出 → 分帳卡 → 同行者**，把自己的名字和同行朋友加進去，之後記錄消費時就可以選誰付款、買給誰。

## 之後：更新到最新版本

原作者加了新功能後，你可以這樣更新（你的行程和相片不會受影響）：

1. 打開你自己的 GitHub 專案（例如 `https://github.com/你的用戶名稱/my-trip`）
2. 按上方的 **Actions** 分頁
   - 第一次打開時，如果看到 **「I understand my workflows, go ahead and enable them」**，按它啟用
3. 左邊選 **「更新到最新版本」**
4. 按右邊的 **Run workflow** → 再按綠色的 **Run workflow**
5. 等約 1 分鐘出現綠色剔號；Cloudflare 會在之後 1–3 分鐘自動重新部署
6. 回到網站，關掉再打開，就是最新版本

啟用後，每星期日也會自動檢查並更新一次。

## 常見問題

**Q：要付錢嗎？**
不用。Cloudflare 免費版包括：每日 10 萬次網站請求、5GB 資料庫空間（每個資料庫上限約 500MB），以及每日一定額度的 AI（用來掃描收據）。個人旅行使用遠遠用不完。

**Q：可以放多少張相片？**
相片會壓縮後存在資料庫，大約可以放一千多張。將來不夠用時，可以再改用 Cloudflare R2 存相片（免費 10GB）。

**Q：原作者看得到我的資料嗎？**
看不到。網站和資料庫都在你自己的 Cloudflare 帳戶。原作者只提供程式，你的帳戶和他的完全無關。

**Q：網址可以改嗎？**
網址是 `網站名稱.你的帳戶子網域.workers.dev`。想改網站名稱，可以在 Cloudflare 的 Workers & Pages → 你的網站 → Settings 修改；你的帳戶子網域可以在 Workers & Pages 主頁右邊的 **Subdomain** 修改。

**Q：忘記裝置密碼怎麼辦？**
在一部已經認證過的裝置，到 **菜單 → 裝置認證** 修改密碼。如果所有裝置都登出了，可以到 Cloudflare → **Storage & Databases → D1** → 你的資料庫 → **Console**，輸入：
```
DELETE FROM settings WHERE key = 'auth';
```
按執行，之後重新打開網站就可以設定新密碼。

**Q：更新時出現紅色交叉？**
到 Actions 分頁按那次執行，看錯誤訊息，或把截圖傳給原作者。你的網站不會因為更新失敗而壞掉，只是仍然是舊版本。

**Q：部署失敗？**
到 Cloudflare → Workers & Pages → 你的網站 → **Deployments** 或 **Builds**，查看紅色的錯誤記錄。最常見是名稱已被使用，換一個網站名稱再部署即可。
